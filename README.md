# 大阪市 営業アタックリスト（社内資料）

建設データバンク関西の建築計画情報から、収集契約につながる大阪市内の新築物件を抽出した営業用の地図・一覧です。

- 公開URL: https://osaka-daisen.github.io/daisen-osaka-list/
- 業務ツールハブ: https://osaka-daisen.github.io/daisen-tools/

優先順位は 事業系テナント → ホテル・民泊 → 共同住宅。完成から1年以上経った物件は除外しています。
検索エンジンには載らないよう noindex を指定していますが、URLを知っていれば誰でも閲覧できます。
